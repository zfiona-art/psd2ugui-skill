# UI 美术制作规范

本规范适用于 Photoshop 画板、图层和切图制作，用于统一 PSD 导出到 Unity 时的预制体结构、组件绑定和资源命名。

## 1 基础规范

- **统一分辨率**：整个项目约定固定的画布大小，例如 `750 × 1624`，不要随意更改。
- **英文命名**：所有画板、组和切图名称只能使用英文字母、数字和下划线，不要使用中文、空格或特殊符号，以免导出或引擎识别异常。
- **清理废稿**：删除隐藏的废弃节点和无关背景节点，保持图层面板干净，避免废弃内容在 Unity 中生成。

## 2 画板与组

- **画板命名**：一个画板对应 Unity 中的一个面板预制体，统一使用 `UI[name]` 格式，例如 `UILoading`、`UIMain`、`UILeaderboard`、`UISetting`。方括号表示名称占位，不写入实际名称。
- **按组归类**：PS 中的一个组，在 Unity 中对应一个父节点，通过组整理节点层级。
- **智能对象**：按钮或徽章由多个图层叠加、剪贴蒙版组合而成，且需要作为一张图片导出时，将这些图层转换为智能对象。

## 3 节点与组件绑定

### 3.1 命名格式

- **图片**：`[公共前缀][类型]_[描述][_后缀]`。公共图片使用 `com_` 前缀，图片类型常用 `img_`、`icon_`、`frame_`，例如 `com_icon_coin`、`img_reward`、`frame_item_selected`。
- **文字**：`[类型]_[描述]`，使用 `title`、`txt_`、`label_` 等类型前缀。
- 方括号表示占位内容，不写入实际名称；公共前缀和后缀按需要添加。

### 3.2 区域组

**全局界面**默认居中对齐。需要靠边对齐的区域组固定命名为 `top`、`bottom`、`left`、`right`：

| 区域组 | 对齐规则 |
| --- | --- |
| `top` | 组内节点向上对齐 |
| `bottom` | 组内节点向下对齐 |
| `left` | 组内节点向左对齐 |
| `right` | 组内节点向右对齐 |

全局界面必须包含 `top` 组，用于自动适配异形屏。

**弹窗界面**由 `mask` 图片和 `content` 组构成。弹窗必须包含 `content` 组，用于自动实现弹出动画。

```text
UIExamplePopup
    mask
    content
```

### 3.3 组件结构示例

**按钮**：文字按钮不用打组，组合按钮需要打组。签到界面的看广告领取按钮示例：

```text
btn_claim_ad
    com_btn_red1_9s
    icon_adSmall
    txt_adReward
```

**复选框**：需要打组，包含选中图和未选中图。

```text
tog_music
    icon_on
    icon_off
    label
```

**输入框**：需要打组，包含底图、有内容时的文本和无内容时的提示文本。

```text
input_email
    frame1
    label_on
    label_off
```

**滑动条**：需要打组，包含背景图和填充图；当前绑定器必须包含 `_move` 滑块节点。

```text
slider_volume
    icon_back
    icon_front
    icon_move
```

**滚动区**：需要打组，按方向使用 `scrollH_` 或 `scrollV_` 前缀，内部包含 `viewport/content` 层级；列表子对象使用 `item_` 前缀。商城物品列表的纵向滚动区示例：

```text
scrollV_shop
    viewport
        content
            item_shop
                btn_frame
                icon_discount
                txt_price
                img_reward
                txt_reward
```

### 3.4 类型前缀与组件对照

“注入组件”表示是否需要通过对应类型绑定组件。组节点以“组”标明，必须包含的子节点以“必需”标明。

| 类型前缀 | 节点形式 | 注入组件 | 描述 | 子节点要求 |
| --- | --- | --- | --- | --- |
| `title`、`label_` | 文本 | 否 | 不需要修改内容的文本 | 无 |
| `txt_` | 文本 | 是，Text | 需要修改内容的文本 | 无 |
| `icon_`、`frame_`、`fx_` | 图片 | 否 | 不需要修改 Sprite 的图片 | 无 |
| `img_` | 图片 | 是，Image | 需要修改 Sprite 的图片 | 无 |
| `group_` | 组 | 否 | 容器父节点，不添加文本或图片 | 按布局组织 |
| `btn_` | 文字或组合组 | 是，Button | 按钮 | 组合按钮的图片和文字放在组内 |
| `tog_` | 组 | 是，Toggle | 复选框 | **必需**：`_on` 选中图片或文本、`_off` 未选中图片或文本 |
| `input_` | 组 | 是，InputField | 输入框 | **必需**：底图、`_on` 有内容文本、`_off` 无内容提示文本 |
| `slider_` | 组 | 是，Slider | 滑动条 | **必需**：`_back` 背景图、`_front` 填充图；**必需**：`_move` 滑块图片 |
| `scrollH_`、`scrollV_` | 组 | 是，ScrollRect | 横向、纵向滚动区域 | **必需**：`viewport` 空节点、`viewport/content` 空节点；列表子对象使用 `item_` 组 |
| `item_` | 组 | 是 | 滚动区域的子对象组 | 放在滚动区域中，不单独出现 |

## 4 图片类型

- **公共图片**：多个画板使用的图片，以 `com_` 开头，例如 `com_icon_coin`。
- **背景图片**：长或宽超过 `1024` 的大图，以 `_bg` 结尾，例如 `frame_level_bg`。
- **九宫格图片**：需要切成九宫格的图片，以 `_9s` 结尾，例如 `com_btn_yellow_9s`。
- **状态图片**：需要显示不同状态时，使用状态后缀，例如 `frame_item_normal`、`frame_item_selected`。

| 图片后缀 | 含义 |
| --- | --- |
| `_normal` | 默认状态 |
| `_selected` | 选中状态 |
| `_disabled` | 不可用状态 |
| `_9s` | 九宫格图片 |
| `_bg` | 背景图片 |

## 5 文字类型

- **字体名称一致**：PS 中使用的字体名称，必须与 Unity 工程中导入的字体名称完全一致。
- **文字大小**：Unity 字号使用整数，PS 字号有小数时按四舍五入取整。
- **文字框大小**：Unity 导出按文字框左上角和字体大小定位。单行文字的文字框尽量贴合文字大小，避免自动调整尺寸异常。多行文字必须在 PS 中手动换行，确保导出时能够识别多行文本。
- **文字描边**：可以设置描边大小、颜色和透明度。

## 6 交付检查

- [ ] 所有画板使用项目约定的统一分辨率。
- [ ] 一个画板对应一个预制体，画板按 `UI[name]` 命名。
- [ ] 画板内需要导出的图片已打绿色标签。
- [ ] 已删除隐藏废稿和无关背景节点。
- [ ] 画板、组和切图仅使用英文、数字、下划线命名。
- [ ] 通过组归类节点，组合图片已按需要转换为智能对象。
- [ ] 全局界面包含 `top` 组；弹窗包含 `mask` 图片和 `content` 组。
- [ ] 组件前缀、必需子节点及滚动区层级符合约定。
- [ ] 公共图片以 `com_` 开头，图片类型及状态后缀正确。
- [ ] 字体名称一致，字号取整，多行文字已手动换行。
