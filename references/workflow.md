# PSD 转 Unity UI 工具使用说明

本工具将 Photoshop PSD 设计稿转换为 Unity UI 资源：读取画板和图层，导出布局 JSON 与 PNG，再生成 UI 预制体、配置交互组件，最后生成 C# 字段并绑定预制体引用。目的是减少手动切图、搭建层级、摆放节点和拖拽组件引用的重复工作。

美术制作和命名约定见 [美术规范](art-spec.md)。本文介绍当前工具实际执行的流程，以及每一步的输入、处理和输出。

## 1 整体流程

```text
PSD 文件或文件夹
    ↓ 导出结构
画板布局 JSON 和画板清单
    ↓ 导出图片
PNG 切图和九宫格边框信息
    ↓ 导出预制体
包含层级、位置、图片、文字的 UI 预制体
    ↓ 绑定组件
按钮、复选框、输入框、滑动条、滚动区和顶部安全区配置
    ↓ 生成脚本
界面脚本和 Item 脚本
    ↓ Unity 编译完成后自动处理
脚本挂载到预制体，序列化字段绑定对应组件
```

工具负责界面资源和代码骨架。按钮点击后的业务、列表数据加载、奖励发放等逻辑仍需开发者编写；最终视觉、交互和屏幕适配需要在 Unity 中检查。

首次接入请先阅读 [新项目接入](new-project.md)，使用技能附带工具，不要求目标项目已有导出器。

## 2 使用前准备

1. 按美术规范整理 PSD：统一画布尺寸、命名和层级，为需要导出的图片设置绿色标签，删除隐藏废稿。
2. 将 PSD 放在项目目录内，例如 `Doc/arrow_snap.psd`。也可以指定项目内文件夹，批量处理其子目录中的 PSD。
3. 将设计稿使用的字体导入 Unity 的 `Assets` 内，确保字体名称能够匹配。
4. 为 Unity 启动的 Python 安装 `psd-tools` 及其依赖。Windows 调用 `python`，其他平台调用 `python3`；图片处理使用 Pillow。
5. 保留项目中的 `Tools/PsdUgui/export_psd.py`，结构和图片导出依赖此脚本。

## 3 打开工具与设置参数

在 Unity 菜单中打开 **Tools → PSD UGUI → Export**。

| 参数 | 作用 | 示例或要求 |
| --- | --- | --- |
| 源地址 | 指定单个 PSD 或递归处理的文件夹 | `Doc/arrow_snap.psd` 或 `Doc`，相对项目根目录，不可超出项目 |
| 选择文件 | 打开 PSD 文件选择器，将所选路径转换为项目内相对路径 | 用于选择单个 PSD |
| UI 导出路径 | 存放布局、切图及预制体 | 例如 `Assets/Art/UI`，必须是 `Assets/` 下的相对路径 |
| 是否有绿色标签 | 勾选后仅导出自身带绿色标签的图片图层 | 不过滤结构中的组、文字及其他节点，也不会删除以前导出的图片 |
| 多行文字行距 | 设置生成预制体时多行 Text 的 Line Spacing 倍率 | 默认 `1`，必须为大于零的有限数值 |

参数会按项目保存到 EditorPrefs。导出期间和 Unity 编译期间不能再次点击执行按钮。

## 4 每个步骤做了什么

### 第一步 导出结构

**输入**：PSD 设计稿。

工具读取画板、组、图层顺序、可见性、位置和大小，并将坐标转换为相对画板的坐标。文字额外读取内容、字体名、字号、颜色及可支持的描边信息。

- 有画板时，每个画板生成一份布局 JSON。
- 没有画板时，将整个 PSD 视为一个界面，以 PSD 文件名作为界面名。
- 每个 PSD 额外生成画板清单，供后续步骤找到该文件对应的全部界面。
- 隐藏节点仍会写入结构，并记录隐藏状态，不会自动当作废稿删除。

**输出**：`Config/psd/<画板名>.json` 和 `Config/psd/Manifests/<PSD文件名>.json`。

这一步只记录布局和资源引用，不导出 PNG，也不创建预制体。

### 第二步 导出图片

**输入**：PSD 图片图层及绿色标签选项。

工具将图片图层渲染为按图层边界裁剪的 PNG。文字保留为后续生成的 Unity Text，普通组用于保留层级；需要合成一张图的内容应在 PSD 中整理为智能对象。

- 以 `_bg` 结尾的图片保存到 `Textures/Big`。
- 其他图片保存到 `Textures/Main`。
- 勾选绿色标签后，仅导出自身带绿色标签的图片图层。
- `_9s` 图片压缩重复的中间行列，保留边缘，并将边框信息写入 PNG 的 `UnityNineSlice` 元数据，不生成额外的 `.9slice` 文件。
- Unity 刷新资源后，会强制重新导入 `_9s` PNG，使边框信息更新到 Sprite。

**输出**：PNG 切图。这一步不更新布局 JSON；布局或绿色标签有变化时，应重新执行“导出结构”，或使用“一键导出”。

图片目录按名称后缀判断，工具不会根据图片尺寸自动追加 `_bg`。

### 第三步 导出预制体

**输入**：已经导出的布局 JSON、PNG 和 Unity 字体资源。

工具读取画板清单，逐个创建界面预制体：

1. 将组转换为父节点，按 PSD 层级和前后顺序创建子节点。
2. 将图片转换为 Image 并查找对应 Sprite；九宫格图片设置为 Sliced。
3. 将文字转换为 Unity UGUI Text，设置内容、字体、整数字号、颜色和 Outline 描边。
4. 按字体测量文字所需尺寸；单行文字居中，多行文字按显式换行识别并使用左上对齐及配置的行距。
5. 恢复节点的位置、尺寸和隐藏状态；隐藏节点生成后处于未激活状态。
6. 根节点设置为拉伸铺满父节点；普通节点使用中心锚点和中心轴心，名为 `top`、`bottom`、`left`、`right` 的节点使用对应边缘锚点，并尽量保留设计稿位置。

**输出**：`Prefabs/UI/<画板名>.prefab`。

缺失图片会汇总到 Console，对应 Image 默认禁用，但仍生成节点；缺失字体会阻止该预制体导出。单独点击此按钮不会执行后续交互组件绑定和脚本生成。

### 第四步 绑定组件

**输入**：已生成的预制体及按约定命名的节点。

工具按名称添加或复用组件，并填写组件间的引用。此步骤中的名称匹配不区分大小写。

| 节点名称 | 实际处理 | 子节点要求 |
| --- | --- | --- |
| `top` | 添加 TopAreaAdapter，运行时根据屏幕顶部安全区调整位置 | 顶部锚点，位于受支持的屏幕空间 Canvas 下 |
| `btn_` | 添加 Button，配置可接收点击的 Graphic | 没有 Graphic 时补充透明 Image 点击区域 |
| `tog_` | 添加 Toggle 和 ToggleStateAdapter，配置选中与未选中显示 | 唯一的 `_on`、`_off` 后缀节点，二者不能相互嵌套 |
| `input_` | 添加 InputField，绑定输入文本和提示文本 | 唯一的 `_on`、`_off` 后缀节点，均须有 Text |
| `slider_` | 添加 Slider，绑定填充区域和滑块 | `_back`、`_front`、`_move` 均须唯一且带 Image；当前实现要求三者齐全 |
| `scrollH_` | 添加横向 ScrollRect，配置裁剪和横向布局 | 唯一的 `viewport`、`content` 节点 |
| `scrollV_` | 添加纵向 ScrollRect，配置裁剪和纵向布局 | 唯一的 `viewport`、`content` 节点 |

滚动区会将层级整理为“滚动区 → viewport → content”，为 viewport 添加 RectMask2D，为 content 添加对应方向的 LayoutGroup 和 ContentSizeFitter。列表保持 PSD 提供的子节点尺寸，位置由布局组件重新排列。

缺少或重复必要子节点、节点类型不匹配时，会报错并停止后续处理。此步骤配置组件关系，不会自动添加业务事件。

**输出**：更新后的预制体。

### 第五步 生成脚本

**输入**：已配置组件的预制体。

工具扫描预制体中的命名节点，生成字段声明，待 Unity 编译后挂载脚本并绑定字段引用。

- 主界面脚本保存在 `Assets/Scripts/View/<预制体名>.cs`，继承项目的 `PsdUguiViewBase`。
- `item` 开头的节点生成独立 MonoBehaviour 脚本，保存在 `Assets/Scripts/View/Item`；Item 内部字段由 Item 脚本管理，不重复收集到主界面脚本。
- 可识别的字段前缀包括 `btn`、`txt`、`slider`、`input`、`tog`、`img`、`rect`、`scroll`。
- 已有脚本主要更新 `AutoGenerated UI Bindings` 区域；业务代码应放在该区域外。
- 生成和更新的 C# 文件使用带 BOM 的 UTF-8 编码；更新时保留原有换行风格。
- 多个画板先统一提交脚本生成，再触发刷新和编译，避免编译重载打断批处理。

**输出**：主界面和 Item 脚本，以及完成脚本挂载和字段引用绑定的预制体。

窗口显示“脚本生成已提交”表示已提交生成流程，仍需等待 Unity 编译和自动绑定完成，并检查 Console。当前脚本扫描前缀区分大小写，建议严格使用约定的小写前缀；同一绑定范围内的字段节点名应唯一，并符合 C# 标识符规则。

### 一键导出

按“结构和图片 → 预制体 → 组件 → 脚本”的顺序执行完整流程，适合首次导出或设计稿整体更新。发生错误时停止后续处理；已经写入的文件不会整体回滚。

## 5 输出目录示例

假设 UI 导出路径为 `Assets/Art/UI`：

```text
Assets/Art/UI/
    Config/psd/
        UIMain.json
        Manifests/
            arrow_snap.json
    Textures/
        Main/
            com_icon_coin.png
            com_btn_yellow_9s.png
        Big/
            frame_level_bg.png
    Prefabs/UI/
        UIMain.prefab

Assets/Scripts/View/
    UIMain.cs
    Item/
        <生成的Item脚本>.cs
```

布局、图片和预制体跟随 UI 导出路径；脚本目录固定在 `Assets/Scripts/View`。图片导入后处理仅从 `_9s` PNG 读取九宫格元数据，常规贴图平台设置遵循目标项目。

## 6 重复导出与日常修改

同一批次内，图片名和画板名按不区分大小写的规则去重，保留先处理的内容，并在 Console 输出跳过信息。输出目录中原有的同名图片、布局和预制体会被重新写入；不再使用的旧文件不会自动清理。应避免不同 PSD 使用相同文件名，因为画板清单以 PSD 文件名保存。

| 修改内容 | 建议执行步骤 |
| --- | --- |
| 首次接入或整体更新 PSD | 一键导出 |
| 仅替换现有同名图片的像素，尺寸不变 | 导出图片 |
| 调整位置、尺寸、文字或层级 | 导出结构 → 导出预制体 → 绑定组件 → 生成脚本；新增或变更图片时同时导出图片 |
| 调整交互节点命名或结构 | 从结构重新导出，再依次执行后续步骤 |
| 在 Unity 中手动调整预制体的组件关系 | 绑定组件 → 生成脚本，按需执行 |
| 仅刷新已有预制体的代码字段引用 | 生成脚本，也可选中预制体执行 Generate UICode |

重新导出预制体会从布局重建内容，手动修改的层级、组件和引用可能被覆盖。设计稿更新后应先保留需要的手工调整，再执行导出。

## 7 完成后检查什么

1. 查看 Console：确认没有导出错误、缺失字体、缺失图片和组件绑定错误；检查同名跳过日志是否符合预期。
2. 等待 Unity 编译完成，打开预制体，检查主脚本、Item 脚本和字段引用。
3. 在 Canvas 下检查图片、文字、层级顺序、九宫格拉伸和多行行距。
4. 验证按钮点击、复选框状态、输入框、滑动条和列表滚动。
5. 在目标分辨率和设备上检查边缘锚点、顶部安全区及弹窗动画。PsdUguiViewBase 使用根节点的直接子节点 `content` 作为动画对象，需启用 animatePopup 并调用 Show/Hide 才播放缩放动画。

## 8 实现入口

| 文件 | 职责 |
| --- | --- |
| `Assets/PsdUgui/Editor/ExportWindow.cs` | Unity 窗口、参数校验、Python 调用、批处理和步骤调度 |
| `Tools/PsdUgui/export_psd.py` | PSD 解析、布局与清单输出、图片与九宫格导出 |
| `Assets/PsdUgui/Editor/ExportPrefabUtil.cs` | 从布局构建 UI 预制体、匹配字体和 Sprite、设置文字与锚点 |
| `Assets/PsdUgui/Editor/PsdPrefabComponentBinder.cs` | 按节点名添加交互组件并配置引用 |
| `Assets/PsdUgui/Editor/TextureImportSettings.cs` | 图片导入设置、读取 PNG 九宫格边框 |
| `Assets/PsdUgui/Editor/UIBindCodeGenerator*.cs` | 扫描预制体、生成字段和 Item 脚本、编译后挂载与引用绑定 |
| `Assets/PsdUgui/Runtime/TopAreaAdapter.cs` | 运行时顶部安全区适配 |
| `Assets/PsdUgui/Runtime/ToggleStateAdapter.cs` | 运行时切换选中和未选中节点 |
| `Assets/PsdUgui/Runtime/PsdUguiViewBase.cs` | 界面基础生命周期和弹出关闭动画 |
